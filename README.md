# ZephyrUrn

ZephyrUrn is a low-latency event-driven platform that enables real-time data processing through a scalable engine.

With ZephyrUrn, you get a lightweight tool that stays out of your way.

**What you get**

- ZephyrUrn is a low-latency event-driven
- platform that enables real-time data
- processing through a scalable engine

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ZephyrUrn.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ZephyrUrn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
